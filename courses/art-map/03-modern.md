| movement | idea | names |
|---|---|---|
| **Fauvism** | wild non-natural colour | Matisse |
| **Cubism** | many viewpoints at once; fractured form | Picasso, Braque |
| **Futurism** | speed, machines | Boccioni |
| **Expressionism** | inner emotion, distortion | Munch, Kirchner, Kandinsky |
| **Dada** | anti-art after WWI's absurdity; readymades | **Duchamp** ("Fountain", 1917) |
| **Surrealism** | dreams, the unconscious | Dalí, Magritte, Ernst |
| **Bauhaus** | art + craft + industry; form follows function | Gropius, Klee, Albers |
| **Abstract Expressionism** | gesture and colour fields; NYC becomes centre | Pollock, Rothko, de Kooning |
| **Pop Art** | mass culture, repetition | Warhol, Lichtenstein |
| **Minimalism** | simple industrial forms | Judd, Agnes Martin |
| **Conceptual art** | the idea is the work | Sol LeWitt, Kosuth |
| **Contemporary** | installation, video, performance, identity | Abramović, Kusama, Ai Weiwei, Hirst |
| **Generative / computational** | rules and code make the work | Vera Molnár, Harold Cohen (AARON), Casey Reas; now AI image models |

**Australian names**: Albert Namatjira (watercolour landscapes), the Western Desert / Papunya Tula painting movement (1971 →; Clifford Possum Tjapaltjarri, Emily Kame Kngwarreye), Sidney Nolan (Ned Kelly series), Brett Whiteley, Tracey Moffatt.
